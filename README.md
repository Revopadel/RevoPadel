# Revo Pádel

Demo instalable de Revo Pádel, la app de pádel para jugadores y clubs: reservas, partidos abiertos con chat, pago dividido, torneos, tienda, nivel, ranking e insignias.

Ábrela en el móvil y pulsa **Instalar aplicación** (Android) o **Compartir → Añadir a pantalla de inicio** (iPhone).

Es una demo: cada móvil guarda sus propios datos y los pagos son simulados.
